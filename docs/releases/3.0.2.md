# ArguLab v3.0.2

**Release: v3.0.2**

26 September 2026 · Compatible API cleanup and release maintenance.

| Before                                                                 | v3.0.2                                                                              |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| One broad API dispatcher and additional dispatch inside domain modules | Explicit route groups for accounts, practice, community, privacy, AI and speech     |
| Frontend and backend repeated URL strings                              | Shared API path contract                                                            |
| An unknown AI path could spend request quota                           | Missing routes return 404 before AI quota checks                                    |
| Malformed review JSON could look like a provider failure               | Invalid JSON returns 400; unsupported methods return 405 with `Allow`               |
| App version remained 3.0.1 after the routing upgrade                   | Synchronized 3.0.2 manifests, runtime health version, documentation and release tag |

## Included work

The routing implementation is recorded by source commit `46c4df3`. It preserves existing URLs, payloads, owner isolation, same-origin account cookies, direct AI streaming and separate speech quotas. The release also includes the visual product/engineering guides and supplied logo added after the v3.0.1 tag.

Small maintenance updates clarify the responsibilities of the upgraded modules. A version preparation/check command and CI gate keep future releases consistent. The [AI task guide](../ai/README.md) explains conversation, review, generation, transcription and read-aloud responsibilities without claiming a separate model for every simulated role.

## Verification

Local release verification passed **58 backend/integration tests, 21 browser tests and four release-tool tests**, type checks, production builds, persistence/import verification and credential scans. Lint passed with 13 existing nonblocking warnings. Release checks validate version consistency and matching shared documentation; 24 documentation pages and 19 Mermaid diagrams were rendered successfully. The release commit's GitHub CI is the source of automated verification status after publication.

## Upgrade

Deploy frontend and backend from the v3.0.2 source release commit on `main`. No new service, dependency, credential or database migration is required for this release. Preserve existing environment settings, cookie names, policy acknowledgements and token scopes. Confirm `/api/health` reports `version: "3.0.2"` after the backend deployment completes.

Google sign-in and recovery email still depend on live provider configuration. This release does not add a new AI provider, paid plan, vocal-delivery grading or legal/accessibility certification.
